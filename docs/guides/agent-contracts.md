# Agent 合同

所有结构化 Agent 都遵循同一最小合同：输入是当前阶段的强类型消息，输出是单个 JSON 对象，业务枚举和必需字段由调用方 Schema 约束。

## 通用规则

- 提示词使用中文描述任务、证据与拒绝条件。
- 源码、路径、模型/API 名称和 JSON 字段保持原样。
- JSON 解析失败时最多修复一次；仍失败则当前项报错。
- 不接受 Markdown 包裹、多对象拼接或缺少必需字段的结果。
- 内部消息直接读取当前字段，不保留旧字段别名。

## 判定阶段

语义审查只依据簇样例、完整支持度和可定位源码上下文。接受结果必须说明稳定语义、适用条件与复用价值；异味审查独立判断是否只是重复、包装、过度抽象或项目偶然结构。

## 合成阶段

规划输入是同一区域内的已接受习语及其匹配位置。计划至少包含两个唯一候选，并说明它们的真实关系；组装结果需通过语法、质量、类型和异味检查。

失败结果应带清楚原因，不增加多层静默回退。
