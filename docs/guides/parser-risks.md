# Parser 风险

零构建解析的主要边界如下：

| 风险 | 当前处理 |
| --- | --- |
| 宏和条件编译破坏语法边界 | 保留 Tree-sitter 诊断并使用有限预处理器影子恢复 |
| 源码不完整 | 保存可定位的恢复函数，脏候选不进入主流程 |
| 模板和复杂声明产生误识别 | 依赖函数声明器、函数体与父子结构共同判断 |
| 超长函数超过模型预算 | 优先保留内聚的语义片段，否则明确拒绝 |
| 重名文件或符号链接越界 | 使用仓库相对路径并由扫描器排除越界路径 |

解析器不会运行预处理器、编译器或构建脚本，因此无法保证完整语义绑定。诊断和覆盖率用于解释输入质量，不应被包装成“全部正确”的保证。

出现问题时先检查 `dataset.audit.json`、原始路径和候选范围，再用最小源码样例补回归测试。
