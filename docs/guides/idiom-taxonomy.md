# 习语类型

当前知识组织分为两类：

| 类型 | 含义 | 聚合方式 |
| --- | --- | --- |
| `cataloged` | 可归入受控目录的通用 C++ 习语 | 按 `catalog_id` 汇总 |
| `repository_specific` | 对当前仓库有价值，但不应泛化为通用类型 | 按项目和记录 ID 保留 |

目录 ID 表达稳定概念，例如 RAII、作用域清理、错误传播、迭代器遍历、类型擦除或异步回调。相似代码只有在语义、适用前提和复用目的均匹配时才共享目录 ID。

新增目录项时直接更新当前目录、提示词和测试。删除或重命名条目时同步更新消费者，不维护目录版本或旧 ID 映射。
