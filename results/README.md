# 正式实验产物

`outputs/` 保存可复用的中间产物，`results/` 保存最终结果。两者均采用
`<scope>/<repository>/...` 的仓库优先结构。生成的二进制产物不进入版本控制，
本页保存 Sol 7.0 的正式指标台账。

## 当前范围

- 15 个 Project 与 15 个 Library 的 Stage 0～2 产物保存在
  `outputs/<scope>/<repository>/stage0..2/`。
- `libzmq`、`drogon`、`qbittorrent` 的主方法 Stage 3、Stage 4 与 baseline
  checkpoint 保存在 `outputs/project/<repository>/`。
- 三仓主方法最终结果保存在 `results/project/<repository>/main/`。
- 三类 baseline 最终结果保存在
  `results/project/<repository>/baselines/<method>/`。

所有方法使用同一固定 70/30 文件划分和 Haggis 留出九项指标合同。主方法汇总位于
`results/project/main-summary.json`，baseline 汇总位于
`results/project/baseline-summary.json`。
